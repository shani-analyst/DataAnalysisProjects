This is an e-commerce sales dashboard which projects total sales YTD, sales based on regions.

This dataset(.csv) is downloaded from Kaggle. As part of ETL, before loading data into powerbi, data was transformed ( datatype changes).

This report also contains Dynamic DLS implementation based on Dimension tables.

For Dymanic DLS, a separate table is created to implement UAC.
